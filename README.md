# 一览

macOS 菜单栏小工具：分应用音量控制 + 系统状态（CPU / 内存 / 磁盘 / 网络 / 电池与实时功率）+ AI 用量（Claude、Codex、Grok Bot）+ 保持唤醒（类似 Amphetamine）+ 消息（微信 / QQ 等未读数与快捷入口）+ 素材（临时截图 / 文件夹，原「素材夹」）。

- 左键：弹出面板（音量 / 状态 / AI / 消息 / 素材 五页）
- 拖到菜单栏图标上：文件或图片直接放进素材页
- Option + 左键：一键开关「保持唤醒」（无限期），开启时菜单栏最左侧显示咖啡杯
- 右键：选择菜单栏显示项、保持唤醒时长（15 分钟～8 小时 / 无限期，可选允许屏幕关闭、合盖也保持唤醒）、素材（从剪贴板添加、在访达中打开、清空、自动收集新截图）、登录时启动、退出

消息页：未读数取自各应用的程序坞角标（需在「系统设置 › 通知」中为其打开「标记」），无需额外权限；「原生菜单」按钮点按该应用自己的菜单栏图标，需要辅助功能权限（ad-hoc 签名，每次重新构建后要重新授权）。菜单栏「消息未读」项只在有未读时出现。

素材页：拖进面板 / 拖到菜单栏图标 / ⌘V 粘贴剪贴板图片 / 自动收集新截图（默认开）。缩略图右下角标注格式，可直接拖出到任意应用；双击打开；右键拷贝、在访达中显示、移出。存的是副本，放在 `~/Library/Application Support/素材夹/`（沿用原素材夹的目录，旧素材自动带过来；移出的项进废纸篓）。

## 构建

```bash
./build.sh
cp -R "build/一览.app" /Applications/
```

需要 macOS 14.2+、Swift 5.9+。Claude 套餐百分比读取钥匙串中 Claude Code 的登录；令牌过期时运行 `claude auth status`，由官方 CLI 自己刷新，本应用不直接刷新。

Grok Bot 用量：在 AI 页登录一次，令牌存入钥匙串的「一览.grok」，与 Grok Bot 应用的登录互不影响。Grok Bot 没有公开的用量 API，这里用的是其私有接口，可能随时失效。

合盖保持唤醒：首次开启时输入一次管理员密码，安装 `/etc/sudoers.d/yilan-pmset`（只允许当前用户免密执行 `pmset -a disablesleep 0/1`）。会话结束、退出或下次启动（崩溃恢复）时自动关回；用电池且电量低于 15% 自动停止。右键菜单「移除合盖辅助…」可卸载。
